# A+ Quest Giver

Interactive CompTIA A+ learning world and quest system.

## Current milestone
Pre-Sprint World Map Interaction Prototype / Visual Map Editor.

The current hosted application intentionally implements presentation and authoring only. Production Game State, Machine State, Quest Runtime, Agent Runtime, XP, saves, quest completion, and permanent unlock rules are not implemented here.

## Included regional artwork
- Troubleshooter's Reach
- The Bit Mines
- Shopping District
- Dispatch

Other regions can receive custom PNG/JPG/WebP artwork through the editor.

## GitHub Pages
The workflow in `.github/workflows/deploy-pages.yml` builds `dist/` and deploys it with GitHub Pages Actions.
